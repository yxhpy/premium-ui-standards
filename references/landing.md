# 落地页与营销页

做落地页、产品发布页、品牌叙事页时读本文件。品牌美术和风格仍由项目或执行者决定；
本文件管的是页面逻辑、素材合同、展示型动效和验收。全局一致与像素检查按 [整页一致性](coherence.md)。

骨架和上限是建议默认，不新增出处。

## 1. 先定五件事

| 要定的事 | 写成什么 |
|---|---|
| 主受众 | 一类人，以及他们此刻在什么场合看到这个页面 |
| 唯一转化目标 | 一个动作，例如开始试用、预约、下载 |
| 价值主张 | 一句话，首屏标题由它而来 |
| 证据或体验 | 让人相信主张的东西：可直接操作的体验、作品、数据、案例 |
| 主要异议 | 读者最可能的两三个疑虑，由 FAQ 或对应区块回答 |

- 没有人可以问时自行假设，并在方案单里逐条标为「假设」。
- 不虚构客户、用户数、奖项、合作品牌和性能数据。没有证据就用可操作的体验代替。

## 2. 类型与骨架

| 类型 | 何时用 | 默认骨架 |
|---|---|---|
| 工具体验型 | 产品能在页面里直接试 | 首屏 → 能力 → 作品或示例 → 可操作体验区 → 步骤 → FAQ → 收尾行动号召 |
| 产品发布型 | 讲清一个产品并引导获取 | 首屏 → 问题与方案 → 功能分节 → 证据 → 获取方式 → FAQ → 收尾行动号召 |
| 品牌叙事型 | 以理念和作品为主 | 首屏 → 分章叙事 → 作品 → 联系方式 |

- 每个区块只做一件事，并能回答「它把读者往转化目标推了哪一步」。答不出就删。
- 骨架是读者的疑问顺序，不是必填栏目：两段回答同一个疑问就合并；体验本身最有说服力时可以提前，甚至直接做成首屏。
- 主行动号召指把人带到转化目标的入口，它的文案和去向全页一致；次要行动号召至多一个。
  体验区里完成任务的操作（导出、生成）用它真实的动作名，不必与入口同名。
- 每个链接和按钮都有真实去向，不放点了没反应的装饰按钮。

## 3. 首屏

- 五秒内能回答三件事：这是什么、给谁用、下一步点哪里。
- 桌面和窄屏的首屏内都要同时出现主张和主行动号召；主视觉可以在窄屏上被部分截断。
- 标题是显示角色，断行人工确定，并在 320 CSS px 宽和 200% 字号下验证不裁切、不压到主视觉。
- 主视觉与标题的视觉重量要分出主次，只让一个做主角。

## 4. 素材合同

素材全部自己生成时，先列矩阵再动手。

| 列 | 内容 |
|---|---|
| 用途 | 用在哪个区块，是语义内容还是装饰 |
| 生成方式 | 脚本、着色器或手绘路径；能重新生成 |
| 原作与页面版本 | 原作尺寸、页面用的派生尺寸和格式 |
| 清晰度 | 固有像素不小于显示宽度乘以设备像素比，默认按 2 倍屏 |
| 降级 | 加载失败或图形不可用时显示什么 |

- 一套素材共用同一组光照、色板和视角规则，否则单张再好，放在一起也不像一家。
- 交付生成器本身、每张素材的参数或随机种子，以及一份清单（尺寸、参数、生成方式）；只写「脚本生成」不算能重新生成。
- 每张素材生成后放到页面里的实际显示尺寸逐张看：有没有锯齿、断纹、色带。只核对文件尺寸或只看缩略图不算看过。
- 首屏素材不懒加载并预留比例；装饰素材对读屏隐藏，语义素材写真实的替代文字。
- 实时渲染和静态后备图要在同一位置、同一尺寸上对齐，切换时不跳。

## 5. 展示型持续动效与即时预览

作品本身就是运动的页面，持续动效属于内容，不受 [动效](motion.md) 中「只回应操作」的限制，但必须同时满足：

- 有可见的暂停控件；系统设置了减少动效时默认静止。
- 画面离开视口或页面转到后台时停止绘制。
- 有静态后备图；没有每秒三次以上的闪烁。
- 帧耗时在目标设备上测过，没测就写「未验证」。

界面自身的过渡仍按动效专题执行。

本地、无副作用、不持久化的调参（换材质、拖滑块看效果）可以即改即看，不需要「应用」或「保存」按钮。
导出、发送、付费这类有结果的动作仍然是显式操作，并按 [异步反馈](async-feedback.md) 给忙碌与失败状态。

## 6. 图形与性能

- 给画布定预算：设备像素比上限、最长边上限、网格规模，数值写进方案单。
- 图形上下文建立失败或丢失时回到静态后备，并保留用户已调的参数。
- 有画布时性能样本换成视觉页的六个：冷加载首屏、画布进出视口、连续调参、减少动效、上下文丢失、高清导出；
  页面没有画布或导出时只取适用的几项，不为了有东西可测而加功能。
  其余指标口径见 [性能观感](performance.md)。

## 7. 验收

- 跑 [普查](coherence.md#4-普查用测量代替目测)，findings 为空或逐条列为例外。
- 实际操作一遍体验区的每个控件和导出，核对导出物的真实尺寸与页面声明一致。
- 过 [审查清单](checklist.md) 的通用组、S 组和 T 组；与本页无关的专用组整组标「不适用」即可。
