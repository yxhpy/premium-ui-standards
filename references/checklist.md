# 审查清单

审查时逐条过一遍。每个问题都要报告：`文件:行号`（截图审查时写位置描述）、违反的条目编号、修改建议。只报告实际看到的问题。

## A. 层次与颜色
- [ ] A1 没有用 1px 实色边框给区块分区（表格、长列表的发丝线除外）
- [ ] A2 背景层级不超过 4 档，相邻层之间是小步明度差
- [ ] A3 没有大面积使用 `#000` 或 `#fff`
- [ ] A4 卡片嵌套不超过 2 层
- [ ] A5 文字对比度：正文 ≥ 7:1（至少 4.5:1），次要文字 ≥ 4.5:1，占位文字 ≥ 3:1
- [ ] A6 灰阶带有品牌色相；颜色定义在 token 里，没有散落的硬编码色值

## B. 字体与排版
- [ ] B1 暗色模式下字重降了一档（或在非可变字体下有说明）
- [ ] B2 会变化的数字用了 `tabular-nums`
- [ ] B3 正文用了 `text-wrap: pretty`，标题用了 `balance`
- [ ] B4 中文正文行高 ≥ 1.7，正文行长不超过约 40em
- [ ] B5 字号阶梯不超过 6 档，最小字号不低于 12px
- [ ] B6 行内图标用了 `1em` 尺寸和 `vertical-align: -0.125em`

## C. 间距与形状
- [ ] C1 间距都在 4px 网格上
- [ ] C2 组内间距小于组间间距
- [ ] C3 嵌套圆角满足「内层 = 外层 − 内边距」
- [ ] C4 点击区域 ≥ 24px（WCAG 2.2 AA 下限），推荐桌面端 ≥ 32px、触屏 ≥ 44px

## D. 交互状态
- [ ] D1 悬停、按下、聚焦、禁用、加载、错误、空状态都有
- [ ] D2 焦点环可见，和背景的对比度 ≥ 3:1，只在 `:focus-visible` 时显示
- [ ] D3 `forced-colors` 模式下，用阴影模拟的边框有替代方案
- [ ] D4 加载提示超过 300ms 才出现
- [ ] D5 错误信息就近显示，并说明怎么修复

## E. 动效
- [ ] E1 动效只用于回应操作或说明变化，没有铺满全站的入场动画
- [ ] E2 拖拽、吸附用咬合型弹簧；点赞、确认用轻快型回弹
- [ ] E3 只动画 transform / opacity / filter
- [ ] E4 瞬时提示 2~3 秒后自动消失，重复触发会重置计时
- [ ] E5 CSS 和 JS 动画都有 `prefers-reduced-motion` 降级
- [ ] E6 折叠展开没有用 JS 算高度

## F. AI 对话（适用时）
- [ ] F1 流式输出有渐显效果，结束后拆掉了动画 span
- [ ] F2 代码块不做逐字动画
- [ ] F3 未闭合的 Markdown 不会闪出原始符号
- [ ] F4 只在用户停在底部时自动滚动
- [ ] F5 输入法组词时按 Enter 不会发送
- [ ] F6 输入框自动长高，并有回退方案
- [ ] F7 生成过程中可以停止，失败后可以重试，且不会丢失输入
- [ ] F8 消息列表滚动条出现时，内容不跳动

## G. 兼容性
- [ ] G1 用到较新的 CSS（`text-wrap: pretty`、`field-sizing`、`interpolate-size`、`text-autospace`）时，不支持的浏览器能正常回退

## H. 反馈与模式（patterns.md）
- [ ] H1 反馈的打扰程度和信息的重要性匹配；重要的失败没有只用自动消失的 Toast
- [ ] H2 带操作按钮的 Toast 停留 ≥ 6 秒，悬停或聚焦时暂停计时
- [ ] H3 危险操作优先做成可撤销；不可逆操作有确认，确认按钮写明对象，默认焦点在「取消」
- [ ] H4 加载：300ms 内不显示，超过 2 秒有说明，长任务可以取消；骨架屏接近真实布局
- [ ] H5 同一个表单没有混用自动保存和手动保存；声明式控件不自动保存
- [ ] H6 保存失败时保留输入；离开页面时提醒未保存的修改
- [ ] H7 表单标签始终可见（不用占位文字代替）；失焦时校验，提交时把焦点移到第一个错误
- [ ] H8 输入框用了正确的 `type`、`inputmode`、`autocomplete`
- [ ] H9 空状态区分「从未使用 / 暂时为空 / 加载失败」，并且有一个主操作
- [ ] H10 已有的数据加载失败时，没有显示成空状态
- [ ] H11 局部故障只降级受影响的部分，全局故障用顶部横幅

## I. 文案与数据（content.md）
- [ ] I1 文案以用户为主体；同一个事物全站只有一个叫法；按钮是明确的动词
- [ ] I2 错误文案说明了哪里错、为什么、怎么改；没有含糊或过于技术化的表述
- [ ] I3 数值有千分位且右对齐；无数据显示 `--`；日期时间格式全站统一
- [ ] I4 相对时间可以查看绝对时间；多语言场景用 `Intl` 格式化
- [ ] I5 敏感信息按规则脱敏

## J. 布局与响应式（layout.md）
- [ ] J1 在 320px 宽（相当于放大到 400%）时不丢功能，也没有双向滚动
- [ ] J2 字号用 rem，尊重浏览器的默认字号
- [ ] J3 移动端处理了安全区；没有用 `100vh` 导致内容被地址栏遮挡
- [ ] J4 z-index 用 token 管理
- [ ] J5 有吸顶元素时设置了 `scroll-padding`，焦点不会被遮挡
- [ ] J6 图片和异步内容预留了尺寸，没有布局跳动

## K. 无障碍（accessibility.md）
- [ ] K1 优先使用原生元素；自定义控件有 role、键盘行为和状态属性
- [ ] K2 弹窗能捕获焦点，关闭后焦点回到触发的按钮；Esc 可以关闭
- [ ] K3 所有拖拽都有点击或键盘替代（WCAG 2.5.7）
- [ ] K4 图标按钮有 `aria-label`，装饰性图片用 `alt=""`
- [ ] K5 动态消息用了 live region；AI 流式输出没有逐字播报
- [ ] K6 页面设置了 `lang`；登录允许粘贴和使用密码管理器
- [ ] K7 适配了 `prefers-contrast` 和 `prefers-reduced-transparency`
- [ ] K8 用 axe 或 Lighthouse 跑过检查，并且只用键盘走通过主流程
