# 审查清单

审查时逐条过一遍。每个问题都要报告：`文件:行号`（截图审查时写位置描述）、违反的条目编号、修改建议。逐项记录是/否及证据；不适用项明确标注场景并跳过，不据截图推断运行行为。只报告实际看到的问题。

## A. 层次与颜色
- [ ] A1 分区优先明度与间距；必要边框有角色理由且交界只绘制一次
- [ ] A2 背景使用四层项目默认或有明确额外角色，相邻层为微明度差
- [ ] A3 按页面底、卡片、浮层等表面角色验收；允许纯白卡片，实际前景/背景对比度达标且层次可辨
- [ ] A4 卡片嵌套不超过 2 层
- [ ] A5 文字对比度：正文 ≥ 7:1（至少 4.5:1），次要文字 ≥ 4.5:1，启用输入框普通占位文字 ≥ 4.5:1
- [ ] A6 灰阶带有品牌色相；颜色定义在 token 里，没有散落的硬编码色值

## B. 字体与排版
- [ ] B1 暗色模式下字重降了一档（非可变字体或可变字体减细后笔画难辨时，可保留原字重并记录可读性证据）
- [ ] B2 会变化的数字用了 `tabular-nums`
- [ ] B3 正文用了 `text-wrap: pretty`，标题用了 `balance`
- [ ] B4 中文正文行高 ≥ 1.7，正文行长不超过约 40em
- [ ] B5 默认字号阶梯不超过 6 档（额外角色有说明），字号使用 rem 且最小 .75rem
- [ ] B6 行内图标用了 `1em` 尺寸和 `vertical-align: -0.125em`

- [ ] B7 触屏或窄屏输入字号默认至少 1rem（默认根 16px），目标 iOS 聚焦已确认，未禁用缩放

## C. 间距与形状
- [ ] C1 间距在 4px 网格或使用有理由的命名光学例外
- [ ] C2 组内间距小于组间间距
- [ ] C3 嵌套圆角满足「内层 = 外层 − 内边距」
- [ ] C4 点击区域 ≥ 24px（WCAG 2.2 AA 下限），推荐桌面端 ≥ 32px、触屏 ≥ 44px

## D. 交互状态
- [ ] D1 悬停、按下、聚焦、禁用、加载、错误、空状态都有
- [ ] D2 内描边加外光晕双环完整，焦点环可见，和背景的对比度 ≥ 3:1，使用 `:focus-visible`，不支持时保留 `:focus` 回退，键盘焦点始终可见
- [ ] D3 `forced-colors` 模式下，用阴影模拟的边框有替代方案
- [ ] D4 默认延迟 300ms 出现加载提示；采用 150~300ms 范围内其他值时有项目记录
- [ ] D5 错误信息就近显示，并说明怎么修复

## E. 动效
- [ ] E1 动效只用于回应操作或说明变化，没有铺满全站的入场动画
- [ ] E2 拖拽、吸附用咬合型弹簧；点赞、确认用轻快型回弹
- [ ] E3 默认动画 transform / opacity；filter 和网格等布局例外有目标设备测量证据
- [ ] E4 不带操作的普通轻提示 2~3 秒后自动消失，重复触发会重置计时
- [ ] E5 CSS 和 JS 动画都有 `prefers-reduced-motion` 降级
- [ ] E6 折叠展开没有用 JS 算高度

## F. AI 对话（适用时）
- [ ] F1 流式输出有渐显效果，结束后拆掉了动画 span
- [ ] F2 代码块不做逐字动画
- [ ] F3 未闭合的 Markdown 不会闪出原始符号
- [ ] F4 只在用户停在底部时自动滚动
- [ ] F5 输入法组词时按 Enter 不会发送
- [ ] F6 输入框自动长高，并有回退方案
- [ ] F7 生成过程中可以停止，失败后可以重试，且不会丢失输入
- [ ] F8 消息列表滚动条出现时，内容不跳动

## G. 兼容性
- [ ] G1 用到较新的 CSS（`text-wrap: pretty`、`field-sizing`、`interpolate-size`、`text-autospace`）时，不支持的浏览器能正常回退

## H. 反馈与模式（patterns.md）
- [ ] H1 反馈的打扰程度和信息的重要性匹配；重要的失败没有只用自动消失的 Toast
- [ ] H2 通知使用初始存在的 polite/status 容器，紧急错误才用 alert，按钮不抢焦点且关闭后有常驻等效入口；带操作按钮的 Toast 停留 ≥ 6 秒，悬停或聚焦时暂停计时
- [ ] H3 危险操作优先做成可撤销；不可逆操作有确认，确认按钮写明对象，默认焦点在「取消」
- [ ] H4 加载按已选延迟显示，超过 2 秒有说明，长任务可以取消；骨架屏接近真实布局
- [ ] H5 同一个表单没有混用自动保存和手动保存；声明式控件不自动保存
- [ ] H6 保存失败时保留输入；离开页面时提醒未保存的修改
- [ ] H7 标签始终可见；失焦校验，提交失败短表单聚焦首错、长表单多错聚焦含字段链接的摘要
- [ ] H8 输入框用了正确的 `type`、`inputmode`、`autocomplete`
- [ ] H9 空状态区分「从未使用 / 暂时为空 / 加载失败」，并且有一个主操作
- [ ] H10 已有的数据加载失败时，没有显示成空状态
- [ ] H11 局部故障只降级受影响的部分，全局故障用顶部横幅

## I. 文案与数据（content.md）
- [ ] I1 文案以用户为主体；同一个事物全站只有一个叫法；按钮是明确的动词
- [ ] I2 错误文案说明了哪里错、为什么、怎么改；没有含糊或过于技术化的表述
- [ ] I3 数值有千分位且右对齐；无数据显示 `--`；日期时间格式全站统一
- [ ] I4 相对时间可以查看绝对时间；多语言场景用 `Intl` 格式化
- [ ] I5 敏感信息按规则脱敏

## J. 布局与响应式（layout.md）
- [ ] J1 水平内容在等效 320 CSS px 宽度不丢功能、整页无双向滚动，必要二维内容只局部滚动
- [ ] J2 字号用 rem，尊重浏览器的默认字号
- [ ] J3 移动端处理了安全区；没有用 `100vh` 导致内容被地址栏遮挡
- [ ] J4 z-index 用 token 管理
- [ ] J5 有吸顶元素时设置了 `scroll-padding`，焦点不会被遮挡
- [ ] J6 图片和异步内容预留了尺寸，没有布局跳动

## K. 无障碍（accessibility.md）
- [ ] K1 优先使用原生元素；自定义控件有 role、键盘行为和状态属性
- [ ] K2 弹窗能捕获焦点，关闭后焦点回到触发的按钮；Esc 可以关闭
- [ ] K3 所有拖拽均有点击 / 轻触的非拖动单指针替代（WCAG 2.5.7），并另行满足键盘可用
- [ ] K4 图标按钮有 `aria-label`，装饰性图片用 `alt=""`
- [ ] K5 动态消息用了 live region；AI 流式输出没有逐字播报
- [ ] K6 页面设置了 `lang`；登录允许粘贴和使用密码管理器
- [ ] K7 适配了 `prefers-contrast` 和 `prefers-reduced-transparency`
- [ ] K8 用 axe 或 Lighthouse 跑过检查，并且只用键盘走通过主流程

## L. 键盘与焦点（[合同](accessibility.md#复合控件键盘合同)）
- [ ] L1 实际使用的菜单、组合框、标签页、列表框逐项符合键盘合同，活动与选中分别可见
- [ ] L2 roving tabindex 只有一个 0，移动后 DOM 焦点同步，Tab 可离开控件
- [ ] L3 原生 showModal 不手写 Tab 循环；cancel/close 清理及归还焦点完整；模态背景不可交互，长内容初始焦点合理，触发器消失仍能归还合理位置
- [ ] L4 中文输入法、输入框和 contenteditable 未误触全局快捷键，嵌套 Esc 仅退出当前层
- [ ] L5 aria-disabled 的鼠标、键盘、程序激活都被拦截；触屏和 focus-within 可发现核心操作
- [ ] L6 文本间距四项覆盖后无裁切；普通指针命令可在松手前取消

## M. 性能观感（[规则](performance.md)）
- [ ] M1 报告区分真实第 75 百分位与实验室结果，真实目标为 LCP≤2.5s、INP≤200ms、CLS≤.1
- [ ] M2 首屏主资源未懒加载，媒体/嵌入预留尺寸，冷缓存字体切换测试真实最长标题、含中文及拉丁词的标题和最长主操作按钮；窄屏与文字放大后无裁切、重叠或关键操作遮挡
- [ ] M3 快速、阈值边界、慢请求均已验证，完成内容未被加载动画阻塞
- [ ] M4 长消息、快速分片、大表格有设备与样本记录，解析/高亮/绘制成本分开归因
- [ ] M5 乐观反馈、业务确认、冲突协调分别记录；倒序失败未覆盖后续修改

## N. 复杂组件（[规则](complex-components.md)）
- [ ] N1 仅当前排序列常驻方向图标及方向文本，未排序仅提示图标；表头按钮无默认边框底色、文字不换行且 aria-sort 同步；筛选校正页码，URL 与历史恢复查询和滚动
- [ ] N2 窄容器固定列计算宽度按约 40% 默认建议或有记录的例外验收，并有收窄或取消策略；滚动容器零内边距、表头上沿无行内容露出；表头/体列宽一致，固定交叉处无遮挡，长内容可完整获取
- [ ] N3 部分选择仅报实际数量并可选全部 N 项，全选后才声明全部结果；批量选择显示数量与范围，三态准确，可退出且未静默跨页全选
- [ ] N4 批处理区分成功、失败、未知，仅重试可确认未成功项并保留幂等身份
- [ ] N5 上传可键盘选择，业务限制前置，逐文件阶段可辨，失败保留名称，取消以确认结果为准
- [ ] N6 命令面板显示对象和禁用原因，危险操作使用安全初始焦点与确认

## O. Token（[规则](token-engineering.md)）
- [ ] O1 基础/语义/组件依赖单向，未知引用、循环与类型问题已检查
- [ ] O2 字号 token 均为 rem，根字号无固定 px/62.5%，用户增大根字号后无截断
- [ ] O3 四种状态的 fg/bg/border 完整，浅暗与复合状态按实际背景验算
- [ ] O4 显式主题优先于系统，首帧/水合/原生控件配色一致
- [ ] O5 z-index 有上下文与 portal 合同，嵌套浮层及 top layer 覆盖已回归

## P. AI 高级场景（[规则](ai-chat.md#来源附件与分支)）
- [ ] P1 引用为真实结构化来源，附件的选择、上传与可读取能力分别说明
- [ ] P2 编辑创建显式分支且保留原结果/附件，发送上下文路径可确认
- [ ] P3 虚拟化补历史保留锚点和焦点，全文搜索或导出可获取未挂载内容
- [ ] P4 完成块缓存稳定，仅活动尾块更新；不完整粗体、围栏、链接均有分片验证
- [ ] P5 工具错误可修正/重试单步，副作用未知先查结果；停止旧运行不覆盖新运行
- [ ] P6 部分答案中断状态可识别，恢复流的生产者停止与客户端断开分别确认

## Q. 展开规则的代码验收

- [ ] Q1 排序按钮可键盘激活，列头 aria-sort 与可见方向来自同一查询状态
- [ ] Q2 表头三态由 checked/indeterminate 驱动，零项与翻页选择范围均有明确结果
- [ ] Q3 固定列与表头交叉处层级正确且背景不透明，滚动后没有错列或文字透出
- [ ] Q4 延迟计时器在请求结束时清理，旧请求不覆盖新请求的忙碌态
- [ ] Q5 函数操作发送时从确认基线计算目标、重绘依次重放；乐观状态由已确认基线加待处理队列重算；两次失败回到基线，不保留失败乐观值
- [ ] Q6 组合框未抢占文本编辑键，首次向上/下移动均命中正确候选，Esc 按层退出
- [ ] Q7 流式完成和停止时均刷新最后尾块，旧运行分片不会写入新答案
- [ ] Q8 字体度量调整值来自实际测量，慢网切换后的真实标题和按钮已复查

- [ ] Q9 刷新骨架保留旧内容 DOM 和尺寸，视觉覆盖后边界不跳，失败恢复旧内容及 stale-error 提示
